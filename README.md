# 🔑 ANONYM KEYS — Telegram Shop Bot

Полноценный бот-магазин для продажи цифровых ключей и подписок в Telegram.

## ✨ Возможности

- 📦 Каталог товаров по категориям
- 💳 Оплата через банковскую карту (ручное подтверждение)
- 🔑 Автоматическая выдача ключей после подтверждения
- 📋 История заказов для пользователей
- 🔔 Уведомления администратору с чеком
- 👨‍💼 Удобная админ-панель прямо в боте
- 📊 Статистика продаж
- 🗝 Управление ключами (добавление, хранение в БД)

## 🚀 Быстрый запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/YOUR_USERNAME/anonym-keys-bot.git
cd anonym-keys-bot
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Создать `.env` файл
```bash
cp .env.example .env
```
Открой `.env` и заполни:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — твой Telegram ID (узнай у [@userinfobot](https://t.me/userinfobot))
- `CARD_NUMBER` — номер карты для приёма оплаты
- `CARD_HOLDER` — имя владельца карты

### 4. Запустить
```bash
python bot.py
```

## ☁️ Запуск на Replit

1. Создай новый **Python Repl**
2. Загрузи все файлы проекта
3. В разделе **Secrets** добавь переменные:
   - `BOT_TOKEN`
   - `ADMIN_IDS`
   - `CARD_NUMBER`
   - `CARD_HOLDER`
   - `BANK_NAME`
4. Нажми **Run** 🟢

> Чтобы бот не засыпал на Replit — используй [UptimeRobot](https://uptimerobot.com) для пингования.

## 🤖 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота |
| `/admin` | Открыть панель администратора |

## 👨‍💼 Панель администратора

Доступна через команду `/admin` (только для ADMIN_IDS):

- **📊 Статистика** — пользователи, выручка, заказы
- **📦 Заказы** — список ожидающих подтверждения
- **🗝 Добавить ключи** — добавить ключи для товара
- **➕ Добавить товар** — создать новый товар

## 🔑 Как работает продажа

1. Пользователь выбирает товар в каталоге
2. Бот показывает реквизиты для оплаты
3. Пользователь платит и отправляет чек (фото/PDF)
4. Чек пересылается администратору
5. Админ нажимает ✅ **Подтвердить**
6. Бот автоматически отправляет ключ пользователю

## 🛠 Технологии

- **Python 3.11+**
- **Aiogram 3.15** — Telegram Bot API
- **SQLite** — база данных (файл `shop.db`)
- **python-dotenv** — переменные окружения
